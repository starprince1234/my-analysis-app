# 功能说明

## 核心功能列表

1. CSV 文件上传与会话化
2. 应力分析动态可视化（GIF）
3. 结节检测与演化跟踪（GIF）
4. 统计特征聚类分析（散点图 + JSON 报告）
5. WebSocket 实时进度反馈

## 功能详情

### 1. CSV 上传与会话化

- 用户在首屏卡片选择 `.csv` 文件后点击上传。
- 后端使用 `uuid.uuid4()` 与安全文件名组合为 `<uuid>_<filename>.csv`，落到 `backend/uploads/`。
- 返回 `filepath` 作为后续任务的唯一引用，同一文件可多次触发不同分析。
- 没有数据库，状态完全靠文件名 + Socket 会话维持。

### 2. 应力分析动图

- 输入：96 列时序数据，时间步从几十到上百行不等。
- 处理：每个时间步重塑为 12×8 矩阵；matplotlib 一帧渲染四个子图：
  - 左上：2D 热力图（`imshow`）
  - 右上：3D 曲面（`plot_surface`）
  - 左下：等高线 + 极值标注
  - 右下：均值/极值/标准差等统计文本
- 输出：50 帧 GIF，由 PIL 合成。
- 使用价值：一眼看出应力分布的空间集中区与时间演化趋势。

### 3. 结节检测动图

- 处理：
  - 将矩阵归一化后用 `GaussianMixture(n_components=2)` 分离前景/背景。
  - `closing(mask, disk(2))` 做形态学闭运算，去除噪声。
  - `regionprops` 提取每个连通域的面积、圆度、平均强度。
- 输出：每帧叠加结节轮廓的 GIF，并在图旁显示当前帧的关键指标趋势。
- 使用价值：把"是否有局部异常"从主观判断变成可观测的曲线。

### 4. 统计特征分析

- 处理：
  - 对 96 列分别做 FFT，取平均幅值组成 96 维特征向量。
  - `StandardScaler` 标准化后 `KMeans(n_clusters=3)` 聚类。
  - 输出二维投影散点图（PNG）与 JSON 报告（每列所属簇 + 簇中心）。
- 使用价值：把"哪些通道行为相近"以图表 + 结构化数据呈现，方便下游分析。

### 5. WebSocket 实时进度

- 算法层每完成一个阶段调用 `progress_callback(percent)`。
- 服务端把回调封装为 `socketio.emit('progress_update', ...)`。
- 前端进度条根据 `progress` 值更新，文案显示当前百分比。
- 失败时统一 emit `error`，前端把上方进度卡切换为错误态。

## 用户流程

```
打开页面
   │
   ▼
[卡片1] 选择 CSV 文件 → 点击上传 → 保存服务器 filepath
   │
   ▼
[卡片2] 点击三选一任务按钮
   │
   ▼
[卡片3] 进度条 + 阶段文案实时更新
   │
   ▼
[卡片4] 显示结果 GIF / 散点图 / JSON 报告
```

## 页面 / 组件 / API 对应关系

| UI 区块            | 前端逻辑（main.js）             | 后端入口                                  |
|--------------------|---------------------------------|-------------------------------------------|
| 卡片1：文件上传    | `fetch('/api/upload', ...)`     | `POST /api/upload`（app.py）              |
| 卡片2：任务按钮    | `socket.emit('start_processing')` | `start_processing` handler（app.py）    |
| 卡片3：进度条      | `socket.on('progress_update')`  | `progress_callback → emit`（logic/*.py） |
| 卡片4：结果展示    | `socket.on('task_complete')`    | 各任务完成分支（app.py）                  |
| 错误提示           | `socket.on('error')`            | 全局异常分支                              |

## 未来可扩展功能

- **任务历史与回放**：引入任务表，支持按链接分享某次结果。
- **多文件批量分析**：一次上传多份 CSV，结果以对比视图呈现。
- **自定义矩阵形状**：让用户在 UI 指定行列，而不是写死 12×8。
- **算法参数面板**：把 KMeans 簇数、GMM 组件数等暴露为可调参数。
- **结果导出**：把 GIF + JSON 打包为 zip 下载。
- **基础鉴权**：登录态 + 任务隔离，避免任意人访问 `/results/`。
- **指标看板**：在结节检测中加入最大结节随时间变化的折线图。
